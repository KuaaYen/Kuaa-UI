## Architecture

### Application Flow

```
src/main.tsx
  └─ ViteReactSSG({ routes })          ← 使用 vite-react-ssg 取代 createRoot，實現 SSG
        └─ RootLayout (path: "/")
             ├─ HelmetProvider          ← 提供 react-helmet-async 的 context
             ├─ MediaTypeProvider       ← 監聽 resize，提供 'pc' | 'tablet' | 'mobile'
             ├─ NavBar                  ← 固定頂部導覽列（響應式）
             ├─ NoiseMask               ← 全頁雜訊材質（純視覺）
             ├─ AnimatedOutlet          ← AnimatePresence 包裹的 <Outlet>，頁面切換時淡入淡出
             └─ ToTopButton             ← 頁面回頂部按鈕
```

### Routing

| `/arts` | `ArtsPage` | 藝術插畫頁 |
| `/documents` | `DocumentsPage` | 元件文件根頁（預設載入 RollingNumbers） |
| `/documents/rollingnumbers` | `RollingNumbers` | |

### Component Architecture

元件依**頁面歸屬**組織，並有獨立的 `shared/` 層：

```
pages/
  landingPage/    ← 功能性 section 子資料夾（hero, slogan, dashboard...）
  artsPage/       ← 單頁，內容集中
  documentsPage/
    componentsList/ ← Sidebar（依分類分組）
    informations/   ← 每個 route 對應一個資料夾
      {component}/
        {Component}.tsx         ← 路由目標元件（SEO + 頁面結構）
        content/
          {Component}Demo.tsx   ← 互動展示
          Snippets.tsx          ← 程式碼片段（使用 Snippet 元件）

shared/
  components/ ← 跨頁重用的 UI 元件
  hooks/      ← 跨頁重用的 custom hooks
  icons/      ← 跨頁重用的 SVG icons
```

**命名慣例**：PascalCase 元件名、camelCase 資料夾名（`landingPage`, `documentsPage`）。元件文件頁統一放在 `documentsPage/informations/`（小寫 i）。

### State Management

無全域狀態管理函式庫。唯一的全域狀態來自 **React Context**：

- `MediaTypeContext`：提供裝置類型（`'pc' | 'tablet' | 'mobile'`）
  - 由 `MediaTypeProvider` 設定（在 `RootLayout` 最外層）
  - 以 `useMediaTypeContext()` hook 取用
  - 斷點：mobile < 600px，tablet 600–1099px，pc ≥ 1100px

其餘狀態以各元件 `useState` / `useRef` 管理（local state）。

## Code Conventions

- **元件命名**：PascalCase（`LandingPage.tsx`, `NavBar.tsx`）
- **資料夾命名**：camelCase（`landingPage/`, `documentsPage/`）
- **CSS class 命名**：kebab-case BEM-like（`navbar-container`, `component-list-item`）
- **Import 路徑**：相對路徑，無 path alias（`../../context/useMediaTypeContext`）
- **TypeScript**：使用 `tsconfig.app.json` 與 `tsconfig.node.json` 分離設定
- **Linter**：ESLint 9（flat config，`eslint.config.js`），含 react-hooks 與 react-refresh 規則
- **Export 方式**：元件使用 `export default`；routes 使用 named export（`export const routes`）
- **動畫**：transition duration 統一 `0.2s ease-in-out`（互動），頁面切換 `0.2s`

## Key Patterns & Utilities

### AnimatedOutlet 模式
兩層 `AnimatePresence` 實作平滑頁面切換：
1. **RootLayout** - 頂層路由切換（`/`, `/arts`, `/documents` 之間）
2. **DocumentsPage** - 元件子路由切換（`/documents/*` 之間）

關鍵：`DocumentsAnimatedOutlet` 必須定義在 `DocumentsPage` 元件外部，避免 `mediaType` 更新時重新掛載造成 React.cloneElement 問題（見 `DocumentsPage.tsx` 第11行的原始碼註解）。

### MediaType 響應式模式
取用方式：
```tsx
const mediaType = useMediaTypeContext(); // 'pc' | 'tablet' | 'mobile'
```
用於條件渲染（`{mediaType === 'pc' && <ComponentsList />}`）與 className 切換（`component-list` vs `component-list-mobile`）。

### Snippet 元件（程式碼展示）
`src/components/pages/documentsPage/informations/sharedComponent/snippets/Snippet.tsx`
- 使用 `react-shiki` (ShikiHighlighter) 做語法高亮
- 延遲載入（`delay` prop + `setTimeout`）避免阻塞首屏
- 支援 `toggleSnippet`（TS/JS 切換開關）
- 高度自動計算（依程式碼行數計算，支援自動捲動）
- `memo()` 包裹避免不必要的重渲染

### Zdog 3D 插畫
使用 `zdog` + `react-zdog` 在 `ArtsPage` 與 Landing `Dashboard` section 渲染偽 3D 插畫，支援滑鼠拖動互動。

### NoiseMask
固定定位的全頁 SVG/Canvas 雜訊材質疊加層，純視覺效果，提升畫面質感。`pointer-events: none` 不影響互動。

### ToTopButton 雙模式
`targetType: 'page'`：將整頁滾動至頂部（`window.scrollTo`）
`targetType: 'component'`：將傳入的 `scrollRef` 元素滾動至頂部（用於 Snippet 長程式碼區塊）
